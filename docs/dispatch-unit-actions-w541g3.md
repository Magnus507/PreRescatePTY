# W5.41G.3 - Acciones reales de despacho por unidad

- `mark-unit-picked` marca separación física de una unidad.
- `mark-prepared` solo avanza cuando todas las unidades fueron separadas.
- `mark-sent` registra salida y actualiza unidades a `dispatched`.
- `confirm-delivery` marca la entrega final sin activar chips.
- `internalLabel` permanece visible durante el flujo operativo.
