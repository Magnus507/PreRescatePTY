## Inventario

- Disponible

- Pendiente QC
- QC fallido
- Despachado
- Entregado
- Activado

## Diferencias importantes

- `Enviar a despacho` no significa `Pedido enviado`.
- `Pedido preparado` no significa `Pedido enviado`.
- `Pedido entregado` no significa chip activado.
- La activación ocurre luego con el código dentro del producto.
