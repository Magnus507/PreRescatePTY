# BRAND-D2-UX1 - Polish de Ancho, Bordes y Colores en Home Cliente

## 1. Qué se cambió en ancho y layout

La home cliente ahora aprovecha mejor el ancho disponible sin perder el carácter premium.

### Ajustes principales

- El hero se siente más ancho y menos comprimido.
- La composición interior del hero usa una proporción más abierta.
- Las cards secundarias se sienten menos encerradas en el centro.
- La experiencia general deja de parecer una hoja centrada y se acerca más a una app viva.

## 2. Qué se cambió en el hero

- Se redujo ligeramente el radio para que no se sienta tan “burbuja”.
- Se controló el halo rojo para que no lave el contenido.
- Se oscureció la base del gradiente para ganar profundidad.
- Se ajustó el glass del preview de perfiles para mejorar contraste.
- Se afinó la sombra para que el bloque se vea más integrado.

## 3. Qué se cambió en cards

### Mis dispositivos

- Base más sólida.
- Superficie más oscura y consistente.
- Badge y botón con mejor legibilidad.
- Menos sensación de zona lavada en la parte superior.

### Tienda

- Gradiente más controlado.
- Acento comercial más limpio.
- Radio más coherente con el resto del sistema.

### Mis pedidos

- Fondo más frío y más integrado.
- Sombra más elegante y menos plana.
- Radio más coherente con hero y cards.

## 4. Qué se cambió en colores y bordes

- Se redujo el blanco lavado en superficies claras.
- Se oscurecieron los fondos semitransparentes del hero y preview.
- Se suavizó el halo rosado/rojo.
- Se unificaron radios entre hero, cards, botones y badges.
- Se mejoró el contraste de labels y textos secundarios.

## 5. Qué se cambió en mobile

- Se mantuvo la estructura.
- Se conservaron botones cómodos.
- Se evitaron radios exagerados que consumen espacio.
- El ajuste mejora legibilidad sin añadir nuevas secciones ni motion.

## 6. Si se tocó layout.tsx

- No se tocó `app/(app)/dashboard/layout.tsx`.
- El ajuste se resolvió en `app/(app)/dashboard/page.tsx`.

## 7. Qué no se tocó

- No se cambió `schema.prisma`.
- No hubo migraciones.
- No se tocó BD.
- No se tocó lógica funcional.
- No se tocó W6.04.
- No se tocó chips, pedidos, tienda o empresarial.
- No se agregaron bloques nuevos ni métricas nuevas.

## 8. Qué queda para BRAND-D3

- Sidebar y navegación con polish.
- Ajustes de composición para navegación lateral si hacen falta.
- Revisión de estados activos en layout general.
- Afinado final de experiencia entre home y shell.

## 9. Conclusión

BRAND-D2-UX1 deja la home más abierta, más consistente y más premium, con mejores radios, colores más sólidos y una sensación de espacio mejor aprovechada en desktop y mobile.
