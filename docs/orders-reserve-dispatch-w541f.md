# W5.41F - Reserva y despacho desde Pedidos

- `Reservar etiqueta interna` aparta unidades trazables.
- `Enviar a despacho` crea el despacho real cuando la reserva está completa.
- `processing` significa trabajo operativo en curso.
- `shipped` significa que el despacho salió.
- `completed` significa entrega confirmada.
