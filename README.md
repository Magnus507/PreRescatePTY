# PreRescatePTY

**MVP de emergencias médicas con chips QR/NFC** - Next.js 15, React 19, Prisma/PostgreSQL, Supabase, Upstash/Redis.

Todo el contenido del proyecto está en [`docs/`](./docs/00-indice/README.md):

- **Mapa funcional** - Website, Panel cliente, Admin, Fichas médicas, Chips
- **Arquitectura** - Estructura actual vs propuesta
- **Auditorías** - Estado del código y plan de mejora
- **Operaciones** - Deploy, variables, runbooks

## 🔧 Quick start

```bash
npm run dev
```

Abrir [http://localhost:3000](http://localhost:3000)
